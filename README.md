# AWS Cloud Engineer Internship

This repository tracks my learning and practical work during my AWS Cloud Engineer internship with IDX Exchange.

I’m using PropertyLite, a small property listing application, to practise deploying and managing applications on AWS.

## What I’m Learning

- AWS account security and IAM permissions
- EC2, storage, databases, and networking
- Infrastructure as code with Terraform
- Containers and deployment automation
- Monitoring, troubleshooting, and cost management

## Tools

- Ubuntu through WSL2
- Python and Flask
- AWS CLI
- Terraform
- Git and GitHub
