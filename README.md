# AWS Cloud Engineer Internship

This repository tracks my learning and practical work during my AWS Cloud Engineer internship with IDX Exchange.

I’m using PropertyLite, a small property listing application, to practise deploying and managing applications on AWS.

## What I’m Learning

- AWS account security and IAM permissions
- EC2, storage, databases, and networking
- Infrastructure as code with Terraform
- Containers and deployment automation
- Monitoring, troubleshooting, and cost management

## Tools

- Ubuntu through WSL2
- Python and Flask
- AWS CLI
- Terraform
- Git and GitHub

## Progress

- Week 0: Completed local setup with Ubuntu through WSL 2, Python, Git, AWS CLI, and Terraform.
- Week 1: Completed AWS fundamentals, IAM account setup, budget alerts, and CLI authentication.
- Week 2: Tested IAM permissions and least privilege using an S3 test user.
- Week 3: Deployed PropertyLite on EC2, tested its endpoints, connected through SSH, and practiced EBS snapshots.
- Week 4: Worked with S3, imported property data into RDS MySQL, ran SQL queries, and tested DynamoDB.
- Week 5: Built a VPC with public and private subnets, connected through a bastion, and tested outbound access through a NAT gateway.
- Week 6: Deployed PropertyLite behind an ALB and Auto Scaling Group. Verified automatic replacement and ran a CPU load test; no scale-out was observed.
